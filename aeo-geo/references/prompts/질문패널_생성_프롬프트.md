# 질문 패널 생성 프롬프트 (핸드북 6-1)

아무 AI 챗봇에 아래를 붙여넣고, 나온 질문 중 5~10개를 골라
`questions.json`의 `questions` 배열에 넣으세요.

```
당신은 [업종, 예: 강남 한방 다이어트 한의원]의 마케팅 전략가입니다.
잠재 고객이 ChatGPT 같은 AI에게 실제로 물어볼 법한 질문을 20개 만들어 주세요.

조건:
1. 구매/방문 의도가 강한 질문(예: "~추천해줘", "~어디가 좋아?")과
   정보 탐색 질문(예: "~비용이 얼마야?")을 절반씩 섞을 것
2. 지역 한정 질문과 전국 단위 질문을 구분해 표시할 것
3. 경쟁이 셀 것 같은 일반 질문과, 우리만 답이 될 수 있는
   뾰족한 질문(니치)을 구분해 표시할 것
4. 표 형식: 번호 | 질문 | 의도(구매/정보) | 범위(지역/전국) | 예상 경쟁도(상/중/하)
```

**선정 팁 (핸드북 8-2)**: 경쟁사 자리에 공공기관·대형 포털·위키류가 뜨는
질문은 보류하고, 조건이 2~3개 붙은 뾰족한 질문부터 패널에 넣으세요.
