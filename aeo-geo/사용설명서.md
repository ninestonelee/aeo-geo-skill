# AEO·GEO 수강생 사용 설명서

수업 배포본 v1.0.0 · 2026-11-20

## 1. 설치

저장소의 README를 따라 Codex 또는 Claude Code의 글로벌 스킬 폴더에 `aeo-geo`를 설치합니다. Python 3.11 이상이 필요하며 필수 pip 패키지는 없습니다. 설치 뒤 다음 메시지에서 사용하거나 새 채팅을 엽니다.

Codex 요청 예시:

```text
$aeo-geo 이 프로젝트에 측정 환경을 만들어줘.
브랜드는 [브랜드], 고객은 [대상], 서비스는 [설명], 경쟁사는 [비교 대상]이야.
질문 후보 20개에서 니치 질문 5개를 골라 무료 데모만 실행해줘.
```

## 2. 직접 작업 폴더 준비

아래 `SKILL_DIR`을 실제 설치 경로로 바꿉니다. Windows에서는 같은 작업을 탐색기로 복사해도 됩니다.

```bash
SKILL_DIR="$HOME/.codex/skills/aeo-geo"
mkdir -p aeo-monitor/prompts
cp "$SKILL_DIR/scripts/aeo_service.py" aeo-monitor/
if [ ! -e aeo-monitor/questions.json ]; then
  cp "$SKILL_DIR/templates/questions.json" aeo-monitor/
fi
cp "$SKILL_DIR"/references/prompts/*.md aeo-monitor/prompts/
cd aeo-monitor
```

기존 질문 파일은 덮어쓰지 않습니다. 엔진은 실행 파일 옆에 결과를 저장하므로 글로벌 스킬 폴더에서 측정하지 마세요.

## 3. 질문 패널

`questions.json`에서 다음 항목을 편집합니다.

| 항목 | 뜻 |
|---|---|
| `brand_aliases` | 브랜드를 확실히 식별하는 이름들 |
| `brand_aliases_weak` | 일반어와 겹쳐 확증이 필요한 이름들 |
| `brand_confirm` | 약한 이름과 같은 답변에 있어야 하는 확증어 |
| `brand_exclude` | 오탐을 부르는 구절 |
| `competitors` | 경쟁사 이름과 별칭 |
| `engines` | 사용할 엔진 목록 |
| `runs_per_question` | 질문별 반복 수, 기본 3 |
| `models` | 엔진별 모델 ID |
| `questions` | 고유 ID·질문·티어, 선택적으로 `watch` |

브랜드를 모르는 고객의 발견 가능성을 보려면 질문에 브랜드명을 직접 넣지 않습니다. 대상·지역·상황·제약을 조합한 질문으로 시작하세요.

초기 설정 후 질문을 추가할 때는 위저드를 사용합니다.

```bash
python3 aeo_service.py keyword add --text "서울 직장인 대상 주말 AI 실습 교육 추천해줘" --tier 니치 --watch
python3 aeo_service.py keyword list
```

위저드는 중복을 검사하고 추가 전 미리보기를 보여줍니다. 워치 질문은 0% 또는 전회 대비 20%p 이상 하락하면 경보로 표시합니다. 삭제는 `keyword remove --id q04`이며 확인 질문이 나옵니다. 비교용 질문 ID를 임의로 바꾸지 마세요.

## 4. 무료 데모

```bash
python3 aeo_service.py all --demo
```

키 파일 로드·네트워크·텔레그램 전송 없이 합성 데이터로 전체 흐름을 실행합니다. 결과:

```text
aeo-monitor/
  data/default/demo-runs/YYYY-MM-DD.json
  reports/default/demo/YYYY-MM-DD_AEO리포트.md
  reports/default/demo/dashboard.html
```

HTML을 브라우저로 엽니다. macOS는 `open reports/default/demo/dashboard.html`, Windows는 탐색기에서 파일을 더블클릭해도 됩니다. 데모 URL과 수치는 예시이며 실제 마케팅 근거가 아닙니다.

## 5. API 키와 실측

실측을 하기로 정한 경우에만 키를 설정합니다.

| 엔진 | 환경변수 |
|---|---|
| OpenAI | `OPENAI_API_KEY` |
| Gemini | `GEMINI_API_KEY_PAID` 우선, 없으면 `GEMINI_API_KEY` |
| Perplexity | `PERPLEXITY_API_KEY` |
| Claude | `ANTHROPIC_API_KEY` |

키는 실행 환경변수와 엔진 옆 `.env`에서 읽습니다. 환경변수는 파일보다 우선하며, 로딩 후 Gemini 유료 키 변수가 있으면 우선 선택합니다. 다른 개인 중앙 파일은 읽지 않습니다.

설치된 `templates/.env.example`은 값이 비어 있는 양식입니다. 에디터로 실제 프로젝트의 `.env`를 만들고 필요한 키만 입력하세요. 실제 값은 채팅·화면 공유·로그에 출력하지 말고 Git에서 제외합니다.

```bash
python3 aeo_service.py doctor
```

`doctor`는 키 존재 여부·질문 수·호출 수·모델을 보여주며 API 호출을 하지 않습니다. 키가 없는 엔진이 있으면 종료코드 1이 나올 수 있습니다. 사용할 엔진만 패널의 `engines`에 남기거나, 실측 시 키 없는 엔진이 제외되는 점을 확인하세요.

```bash
# 엔진별 실제 테스트: 비용 발생 가능
python3 aeo_service.py doctor --live

# 실측: 기본 질문 수 × 사용 가능한 엔진 수 × 반복 수
# 알림을 요청하지 않았다면 텔레그램 전송을 비활성화
TELEGRAM_BOT_TOKEN="" TELEGRAM_CHAT_ID="" python3 aeo_service.py all
```

Windows PowerShell에서는 명령 앞의 `VAR=value` 문법 대신 `$env:TELEGRAM_BOT_TOKEN=""`, `$env:TELEGRAM_CHAT_ID=""`를 각각 설정하고 명령을 실행합니다. 알림을 사용할 목적이 없다면 텔레그램 키를 설정하지 않으면 됩니다.

질문 5개 × 엔진 4개 × 3회는 60회입니다. 테스트 호출과 검색·토큰 비용은 별도일 수 있습니다. 실제 모델 가용성과 계정 요금은 제공사에서 확인해야 하며 고정 금액을 보장하지 않습니다. 소비자 앱의 구독과 API 결제는 같은 설정으로 취급하지 마세요.

실측 결과는 `data/default/runs/`와 `reports/default/`에 저장됩니다. 실제 `all`·`report`는 텔레그램 토큰과 채팅 ID가 있으면 요약을 전송할 수 있습니다. 데모는 설정과 관계없이 전송하지 않습니다.

## 6. 결과 해석과 개선

- 언급률은 오류를 제외한 성공 응답 중 브랜드가 언급된 비율입니다.
- 미측정과 오류는 0%가 아닙니다. 엔진 커버리지를 먼저 확인하세요.
- 0%는 이번 표본의 미언급이지 AI가 브랜드를 영구적으로 모른다는 증거가 아닙니다.
- API 응답은 소비자 앱 화면과 다릅니다. 조건을 유지하며 추세를 보세요.
- 최근 4회 이동평균은 주 1회 실행할 때 4주 평균입니다.
- JSON에는 최대 200자 답변 발췌가 저장됩니다. 전체 답변 보관본이 아닙니다.

낮은 언급률 질문을 골라 `prompts/GEO_리라이트_프롬프트.md`로 기존 글을 보강합니다. 서두에 직접 답변을 쓰고 사실로 확인되는 근거·출처·FAQ를 더하세요. 없는 통계·고객 발언은 만들지 않습니다. 질문·별칭·엔진·모델을 바꾸면 비교 기준도 달라집니다.

동일 날짜·패널·모드로 다시 실행하면 기존 기록과 리포트가 덮어써집니다. 이미 전달한 결과는 같은 날짜로 재생성하지 마세요.

## 7. 여러 패널과 명령 모음

다른 브랜드는 `panels/brand-b.json`처럼 새 패널을 만들고 명령에 `--questions panels/brand-b.json`을 붙입니다. 파일명이 패널 이름이 됩니다.

```bash
python3 aeo_service.py all --demo --questions panels/brand-b.json
python3 aeo_service.py keyword list --questions panels/brand-b.json
```

| 명령 | 용도 |
|---|---|
| `--help` | 전체 옵션 |
| `doctor` | 비용 없는 설정 점검 |
| `doctor --live` | 엔진별 실제 테스트 |
| `all --demo` | 무료 합성 데이터 전체 흐름 |
| `all` | 실측·리포트·HTML |
| `run` | 측정 기록 생성 |
| `report` | 최근 실측 리포트 재생성, 텔레그램 설정 시 전송 가능 |
| `dashboard` | 최근 실측 HTML 재생성 |
| `report --demo` | 데모 리포트 재생성, 알림 없음 |
| `dashboard --demo` | 데모 HTML 재생성 |
| `health` | 로컬 측정 주기·엔진 결손 점검 |
| `keyword add / list / remove` | 질문 추가·조회·삭제 |

## 8. 자주 막히는 지점

| 증상 | 확인할 것 |
|---|---|
| 스킬이 보이지 않음 | `aeo-geo/SKILL.md` 구조, 설치 경로, 새 메시지·채팅 |
| `python3`를 못 찾음 | Python 설치, Windows의 `py -3` 또는 `python` |
| 질문 파일이 없음 | 엔진을 프로젝트에 복사했는지, 질문 파일이 엔진 옆에 있는지 |
| 키 없음 | 실제 사용할 엔진의 키 이름과 설정 위치. 값은 출력하지 않음 |
| `401`·`403` | 키 유효성·API 사용 권한·계정 상태 |
| `429` | 제공사별 사용 한도·청구 설정. 특정 무료 한도를 고정값으로 가정하지 않음 |
| 모델·검색 도구 오류 | 패널의 모델 ID와 제공사의 현재 지원 조건 |
| 앱 화면과 결과가 다름 | API 측정의 한계이며 같은 조건의 추세로 해석 |

예약 실행, 알림, 웹 공개는 수업 설치 과정에서 자동 설정하지 않습니다. 필요한 경우 실행 환경·시각·비용·공개 범위를 정해 별도 진행하세요.
